The quiz is graded. Find the highest score in the class and how many students got it.

## Input

The first line has N, the number of students. The second line has N scores separated by spaces.

## Output

Print two integers on one line, separated by a space: the highest score, then how many students got that score.

## Constraints

- 1 ≤ N ≤ 1,000
- Each score is a whole number from 0 to 100.
