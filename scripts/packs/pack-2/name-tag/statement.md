Warm-up: print a name tag for the club fair. Read a first name and a grade, and print them in the tag format.

## Input

The first line has a first name. The second line has the grade, a whole number.

## Output

Print `NAME, grade G` where NAME is the name and G is the grade. For example, `Maya, grade 10`.

## Constraints

- The name has 1 to 20 letters.
- 9 ≤ G ≤ 12
