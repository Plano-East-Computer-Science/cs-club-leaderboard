At the club fair everyone signs one sheet, one name per line. Some students sign more than once. Print each name once, in the order it first appears on the sheet, with how many times it appears.

## Input

The first line has N, the number of lines on the sheet. Each of the next N lines has one name.

## Output

For each different name, in order of its first appearance, print the name and its count separated by a space, one name per line.

## Constraints

- 1 ≤ N ≤ 2,000
- Each name is 1 to 10 lowercase letters. Names that are spelled the same are the same student.
