The track team is running a two-person relay. There are N runners, and N is even. Each runner has a speed rating, and a pair's total is the sum of its two ratings.

The coach wants to split all N runners into pairs so that the largest pair total is as small as possible. What is that smallest possible largest total?

## Input

The first line has N. The second line has N ratings separated by spaces.

## Output

Print one integer: the smallest possible value of the largest pair total.

## Constraints

- 2 ≤ N ≤ 1,000 and N is even
- 1 ≤ each rating ≤ 1,000,000
