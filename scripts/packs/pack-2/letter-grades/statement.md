Turn each test score into a letter grade:

- `A` for 90 to 100
- `B` for 80 to 89
- `C` for 70 to 79
- `D` for 60 to 69
- `F` for anything below 60

## Input

The first line has N, the number of scores. The second line has N scores separated by spaces.

## Output

Print N lines: the letter for each score, in the order the scores were given.

## Constraints

- 1 ≤ N ≤ 1,000
- Each score is a whole number from 0 to 100.
