The scorebook lists how many points each player scored in tonight's basketball game. Print the team's total.

## Input

The first line has N, the number of players. The second line has N integers separated by spaces: the points each player scored.

## Output

Print one integer: the sum of all N scores.

## Constraints

- 1 ≤ N ≤ 1,000
- Each score is between 0 and 1,000.
